# 新GT実験の概要

<p class="doc-meta"><span class="chip chip-note">Note</span> <span class="chip chip-date">29-10-2026</span></p>

English version: [New GT experiment](new-gt-experiment-en.md)

この資料は、新しい正解データ（GT: ground truth）を集める実験の概要です。GTとは、各ストップで「本当にどこにいたか」が分かっているGPSデータのことです。参加を考えている研究室のメンバー向けです。

## 1. 目的

前回の実験では、決められたシナリオに沿って動いてもらいました。今回はシナリオがありません。参加者は自分のスマートフォンを使い、新しい場所で、自由に過ごします。そのため、実際の生活に近いデータが集まります。

## 2. 概要

| 項目 | 内容 |
| --- | --- |
| 参加者 | 学生 約20名 |
| 場所 | [TBD]（Airbnbに宿泊） |
| 期間 | 2〜3日（日程: [TBD]） |
| GPS | 自分のスマホ + Reemさんのアプリ（アプリ名: [TBD]） |
| 謝礼 | [TBD] |

## 3. 参加者がすること

- 好きなように過ごしてください。決まったルートやグループのルールはありません。一人でも、誰かと一緒でも自由です。
- 期間中は、アプリをずっと動かしておきます。
- ストップの始まりと終わりに、ボタンをタップします（5を参照）。
- 毎晩10分ほど、その日の記録を見直します（6を参照）。

## 4. 「ストップ」とは

同じ場所に**5分以上**いたら、1つのストップです。歩いて通り過ぎただけの場所は記録しません。ストップには3つのタイプがあります。

| タイプ | 例 |
| --- | --- |
| 建物 | 店、レストラン、カフェ、美術館。同じ建物の中なら、階を移動しても1つのストップ。 |
| 道路 | 歩道で人を待つ、道ばたの屋台の前で立ち止まる。 |
| 屋外空間 | 公園、広場、川沿い。 |

どのタイプか迷ったとき（屋根のある商店街、地下街、店のテラス席など）は、近いタイプを選び、音声メモで状況を一言説明してください。

## 5. 記録の方法

記録には [TBD: アプリ内のボタン、またはフォーム] を使います。一人ひとりが自分のストップを記録します。

- ストップが始まったら「開始」、終わったら「終了」をタップします。時刻は自動で記録されるので、時計を見て書く必要はありません。
- タイプ（建物 / 道路 / 屋外空間）を選びます。
- 場所の名前は、3秒ほどの音声メモで言うだけでOKです（任意）。例：「ローソンに入る」。録音するのは自分の声を数秒だけです。
- 写真を撮ると撮影時刻が残るので、あとで確認するときに役立ちます（任意）。
- タップを忘れたら、気づいたときに記録するか、夜の見直しで追加してください。

## 6. 毎晩の振り返り

- 約10分です。その日のGPSの軌跡を地図で見ます（見る方法: [TBD]）。
- 抜けているストップを追加し、ずれている時刻を直します。
- 記憶が新しいうちに、その日のうちに行ってください。

## 7. スマホの準備

iPhoneもAndroidも、裏で動いているアプリを止めることがあります。出発前に次を確認してください。

- [ ] アプリをインストールし、事前に試した
- [ ] 位置情報を「常に許可」、「正確な位置」をオン
- [ ] このアプリの省電力（バッテリー最適化）をオフ
- [ ] モバイルバッテリーを持っていく
- [ ] スマホの機種とOSのバージョンを担当者に伝える

## 8. プライバシー

- 参加の前に同意書に署名します。
- 集めるもの：GPSの位置と時刻、タップの記録、音声メモと写真（任意）、スマホの機種。
- 宿泊先（Airbnb）の位置は、分析では隠します。
- 記録はいつでも一時停止できます。止めていた時間を担当者に伝えてください。
- データを見られる人と保存期間：[TBD]

## 9. スケジュール

1. 試行：2〜3人で半日、アプリと記録方法を試す（[TBD]）
2. 説明会：全員にやり方を説明し、スマホの設定を一緒に確認する（[TBD]）
3. 本番：2〜3日（[TBD]）
4. 毎晩：データをアップロードし、担当者がアプリが止まっていないか確認する
